# Mechanic Script Assets

This folder should contain the following image assets for the mechanic UI:

## Required Images:
- `logo.png` - Mechanic shop logo (recommended: 200x80px)
- `wrench.png` - Wrench icon for repair options (recommended: 32x32px)
- `engine.png` - Engine icon (recommended: 32x32px)
- `body.png` - Body icon (recommended: 32x32px)
- `parts.png` - Parts icon (recommended: 32x32px)
- `tools.png` - Tools icon (recommended: 32x32px)

## Image Formats:
- PNG format recommended for transparency
- JPG acceptable for photos
- Keep file sizes under 100KB each for optimal performance

## Placeholder Images:
If you don't have custom images, you can use any mechanic-related icons or create simple colored squares as placeholders.
